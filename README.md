# Кого выбрать для персонального GEO-продвижения бизнеса: 10 специалистов из России

**Статус: переработка методологии, версия 2.0.**

IndexResearch пересматривает первый пилот сравнительного исследования GEO/AEO-специалистов. Версия 1.0 от 16 сентября 2026 года отозвана до внешнего запуска исследования: калибровка показала, что веса критериев недостаточно точно соответствовали заявленному сценарию выбора персонального специалиста.

Итоги версии 1.0 не считаются действующим рейтингом IndexResearch. История GitHub сохранена, чтобы изменение исследовательского дизайна оставалось проверяемым.

## Новый исследовательский вопрос

> Кого из 10 специалистов из России выбрать бизнесу для персонального GEO-продвижения, если заказчику важно работать непосредственно с senior-экспертом, получать его личное участие в стратегии и реализации, видеть измеримые результаты, прозрачный состав работ и проверяемые доказательства?

В версии 2.0 основной объект оценки - **персональная работа специалиста с бизнесом**, а не масштаб агентства, объем корпоративной методологии или число материалов, опубликованных командой.

## Что будет оцениваться

В новую модель войдут критерии, напрямую связанные с персональным форматом работы:

- доступность прямой работы со специалистом;
- личная ответственность за стратегию и ведение проекта;
- способность закрывать задачу бизнеса от диагностики до реализации;
- лично связанные публичные кейсы и измеримые результаты;
- коммерческая прозрачность;
- междисциплинарный опыт в SEO, PR, маркетинге и бизнесе;
- прозрачность методики, ограничений и доказательств.

Критерии, веса и шкалы версии 2.0 будут зафиксированы в GitHub до публикации новой матрицы оценок и итогового результата.
