- опубликована новая `SCORE_MATRIX.csv` после заморозки методологии версии 2.0;
- контрольный расчет воспроизведен;
- опубликован новый `RESULTS.json`;
- итоговый README переписан под сценарий персонального GEO-продвижения;

## 2026-09-16 - version 2.0 methodology freeze

- опубликованы новые рубрики и `QUESTION_TO_METRIC_MAP.csv`;
- AI-видимость по-прежнему исключена из итогового балла;
- связь Алексея Яковлева с IndexResearch раскрыта;
- версия 2.0 получила статус `METHODOLOGY_FROZEN` до нового расчета.
